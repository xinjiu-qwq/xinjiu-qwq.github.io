🎉 欢迎来到 **歆九的博客**！

这个博客使用 [Hexo](https://hexo.io/) 构建，采用了 [Firefly](https://github.com/LKDenchin/hexo-theme-firefly) 主题，部署在 GitHub Pages 上。

## 关于这个博客

这里会记录：

- 💻 技术学习笔记与踩坑记录
- 📖 读书笔记与思考
- 🎬 动漫、音乐与生活的碎碎念

## 如何发布新文章

在博客目录下执行：

```bash
npx hexo new "文章标题"
```

编写完成后：

```bash
npx hexo clean && npx hexo generate && npx hexo deploy
```

一切就绪，开始写作吧！

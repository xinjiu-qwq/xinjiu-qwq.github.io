CSS 实现 Material 3 状态层与涟漪效果

2024年12月10日 阅读 8 分钟

Material 3 的交互反馈由两部分组成：状态层（悬停 / 聚焦 / 按下的半透明遮罩）和涟漪（点击扩散的水波）。这篇文章用纯 CSS + 少量 JavaScript 把它们还原到网页上。

状态层:半透明遮罩

M3 规定状态层是组件前景色（on-surface / on-primary 等）的透明叠加：悬停 8%、聚焦 10%、按下 10%。用 color-mix() 可以非常优雅地实现：

.btn {
    position: relative;
    transition: background-color .2s ease;
}
/* 悬停状态层:前景色 8% 叠加 */
.btn:hover {
    background: color-mix(in srgb, var(--md-on-primary) 8%, var(--md-primary));
}
/* 按下状态层:10% */
.btn:active {
    background: color-mix(in srgb, var(--md-on-primary) 10%, var(--md-primary));
}

关键在于把颜色都抽成 CSS 变量，这样无论主题怎么变，状态层永远是正确的。

涟漪:点击扩散的圆

涟漪的本质：在点击坐标生成一个圆形，然后放大并淡出。用事件委托监听 pointerdown，为每个带 .ripple 的元素动态插入圆点：

document.addEventListener('pointerdown', (e) => {
    const host = e.target.closest('.ripple');
    if (!host) return;

    const rect = host.getBoundingClientRect();
    const size = Math.max(rect.width, rect.height) * 1.1;
    const ink = document.createElement('span');
    ink.className = 'ripple-ink';
    ink.style.width = ink.style.height = size + 'px';
    ink.style.left = (e.clientX - rect.left - size / 2) + 'px';
    ink.style.top  = (e.clientY - rect.top - size / 2) + 'px';
    host.appendChild(ink);
    ink.addEventListener('animationend', () => ink.remove());
});

配合 CSS 动画，圆点从 0 放大到 2.2 倍并淡出，就得到了 M3 的涟漪效果。

别忘了无障碍

动画对部分用户是干扰，务必提供关闭入口：

@media (prefers-reduced-motion: reduce) {
    .ripple-ink { animation: none; display: none; }
}

状态层解决"看得见"，涟漪解决"摸得着"。两者结合，网页交互才有接近原生的质感。

小结

这套实现已经用在本站的按钮、卡片和导航上——点一下右上角的主题按钮，就能看到涟漪的完整效果。

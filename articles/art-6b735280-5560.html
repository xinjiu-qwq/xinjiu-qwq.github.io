自我介绍

2026年08月23日 阅读 3 分钟

你好，我是歆九 👋

一个对计算机充满好奇的 INFP 高中牲。

正在一边写代码，一边学着成为一个更温暖的人。

🧩 关于我与代码

从初中开始，我就一直想搭建一个属于自己的博客。

WordPress 试过，第三方托管也折腾过——

兜兜转转，最后发现 GitHub Pages 才是最趁手的方案。

只要在本地写好，push 上去，就完成了。简单、干净、自在。

这是我第一个 Vibe Coding 下真正跑通的项目。

以前那些要么配置不会弄，要么代码报错不会修，

直到遇上 HTML——简单易懂，像终于对上频率的对话。

🎸 关于我与乐队

我喜欢的第一个角色，是《孤独摇滚》里的 喜多。

她阳光、开朗、很会照顾人，

是我想要成为的那种人。

后来也觉得 由乃 很帅——

她把喜欢的事做成了工作，那种笃定和力量，让我很向往。

🚀 关于未来的我

我希望以后能进入计算机专业学习，

能在 GitHub 上更多地 contribute，

也能一步步靠近「把热爱变成日常」的样子。

我是歆九，正在一边写代码，一边学着更勇敢地面对世界。

很高兴认识你 ✨
